
# 😱 Nos vemos mañana - Juego Unifranz

**"Nos vemos mañana"** es un videojuego de terror psicológico y supervivencia en 3D desarrollado en **Unity**, ambientado en las aulas y pasillos de la universidad **Unifranz**. El juego recrea la peor pesadilla que le puede ocurrir a un estudiante durante un día común de clases.

##  Cómo Abrir y Ejecutar el Proyecto

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Mel612/1510JuegoProg.git
   ```

2. **Abrir en Unity Hub:**
   - Abre **Unity Hub**.
   - Haz clic en **Add** (Añadir) y selecciona la carpeta raíz del proyecto clonado.
   - Abre el proyecto.

3. **Ejecutar:**
   - Ve a la carpeta `Assets/Scenes/` y abre la escena del juego.
   - Presiona el botón **Play** ▶️ en el editor de Unity.
